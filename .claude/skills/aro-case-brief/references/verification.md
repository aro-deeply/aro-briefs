# 검증 규칙

브리프의 신뢰는 수치에서 나온다. 한 개라도 틀리면 스터디 참가자 중 누군가는 알아본다.

## 규칙

1. **원출처 우선.** 발표 기관(한국은행, 통계청/국가데이터처, 고용정보원, 노동연구원, 경총, 국회예산정책처, OECD 등)의 원문 또는 그 기관을 직접 인용한 언론 보도에서 확인한다. 블로그, 요약 뉴스레터, 다른 AI의 출력은 출처가 아니다.
2. **수치 + 방향 + 분모.** 값 자체, 전년 대비 방향, 조사 대상(몇 개사, 몇 명, 어느 기간)을 함께 적는다. "67.6%"는 "100인 이상 500개사 중 67.6%, 2025년 81.6%에서 하락"이어야 한다.
3. **확인 안 되면 미수록.** 그럴듯한 수치를 남겨두지 않는다. 출처 섹션에 "○○ 수치는 공개자료에서 확인되지 않아 제외했다"고 쓴다. 이렇게 쓰는 것 자체가 브리프의 신뢰를 올린다.
4. **반대 증거 의무.** 주제 방향과 반대되거나 유보하는 공식 자료를 최소 하나 찾아 신호표에 한 행으로 넣고, "읽는 법"에서 왜 결론이 갈리는지(분석 단위 차이, 데이터 차이) 설명한다.
5. **시나리오 표시.** 인과가 입증되지 않은 연결(A가 늘어 B가 줄었다)은 문장 안에 "입증된 사실이 아니라 시나리오다"라고 쓴다.
6. **날짜 표기.** 정확한 발표일이 확인되면 YYYY.MM.DD, 보도일만 확인되면 YYYY.MM까지만 쓴다.

## 조사 순서

1. 초안의 수치를 목록으로 뽑는다 (기관, 값, 초안이 주장하는 의미).
2. 기관명 + 핵심 숫자로 검색한다. 한 번에 안 나오면 기관명 + 보고서 제목으로 다시.
3. 확인된 것, 방향이 다른 것, 확인 안 된 것으로 분류한다.
4. 조사 중 만난 **초안에 없던 더 강한 사실**을 따로 적는다. 이것이 대개 브리프의 핵심 인사이트가 된다.
5. 해외 대조 자료 하나를 찾는다. 다른 데이터에서 같은 결론이 나오면 한 문단으로 넣는다.

## 실제 사례 (2026.09, 청년채용·숙련형성 브리프)

ChatGPT 초안을 검증했을 때 발생한 것들. 다음 브리프에서 같은 종류의 함정을 예상하라.

| 초안 내용 | 검증 결과 | 처리 |
|---|---|---|
| 경총 "직무 경험 67.6%"를 경험 요구 강화 근거로 사용 | 값은 맞지만 2025년 81.6%에서 하락한 수치 | "요구는 유지되나 더 심해졌다고 쓰면 틀린다"로 정정 |
| 노동연구원·에버트재단 심포지엄 "AI 사용률 37.1%, 업무활용률 51.8%" | 심포지엄 개최는 확인, 수치는 어떤 공개자료에도 없음 | 미수록, 출처 섹션에 명시 |
| OECD 56.5%, 32.2%, 38.3%, 42% | 원문 확인 불가 | 확인된 71%, 17.2%, 35.1% vs 50.8%, 53.0%로 교체 |
| "미국 Census, PwC 자료도 같은 방향" | 본문에 실제 내용 없음 | 제외, 검증 가능한 Stanford Canaries 연구만 수록 |
| 국회예산정책처 2026.02.24 | 보도일 기준 2.27~28 | "2026.02"로 표기 |

조사 중 새로 발견해 핵심으로 세운 것: 한국은행·스탠퍼드가 서로 다른 데이터에서 "조정은 해고가 아니라 채용 축소로", "감소는 자동화형 사용에 집중"이라는 같은 두 결론을 냈다는 점. 같은 업종에서 청년 -26.8만·50대 +17.3만이라는 세대 교체 수치. 이런 발견이 초안의 일반론을 대체한다.
