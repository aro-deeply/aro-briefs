# ARO Case Brief 아카이브

HR 스터디용 케이스 브리프를 모아두는 저장소. GitHub Pages로 공개됩니다.

## 구조

```
index.html                       목록 페이지 (새 편은 카드 하나 추가)
briefs/
  YYYY-MM-DD-slug/
    index.html                   웹 판
    brief.pdf                    인쇄 판
```

## 새 브리프 추가

1. `aro-case-brief` 스킬로 HTML과 PDF를 만든다.
2. `briefs/날짜-슬러그/` 폴더에 `index.html`, `brief.pdf`로 넣는다.
3. `index.html`의 `<div id="list">` 맨 위에 카드 하나를 추가한다 (기존 카드 복사 후 제목·부제·한 줄 결론·태그·링크만 교체).
